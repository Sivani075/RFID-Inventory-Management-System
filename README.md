# RFID Inventory Management System

This project is an RFID-based Inventory Management System developed using ESP32, RC522 RFID Reader, OLED Display, and Buzzer.

The system scans RFID tags, identifies inventory items, updates stock information, displays item details on an OLED screen, and generates alerts for unauthorized tags.

## Features

- RFID-based item identification
- Inventory stock monitoring
- OLED display output
- Authorized and unauthorized tag detection
- Buzzer alerts
- ESP32-based implementation

## Components Used

- ESP32
- RC522 RFID Reader
- RFID Tags
- OLED Display (SSD1306)
- Buzzer
- Breadboard
- Jumper Wires

## Output

- Reads RFID tag UID
- Identifies inventory items
- Updates stock count
- Displays item information on OLED
- Generates alert for unknown tags
